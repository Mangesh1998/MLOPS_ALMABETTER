# 🚀 Travel & Tourism Analytics — Local Setup Guide

## Overview

This project contains **3 independent ML subsystems** and MLOps infrastructure:

| Module | ML Model | Interface |
|--------|----------|-----------|
| `Travel_ML_System/` | Flight Price Prediction (Random Forest) | Flask API + Streamlit |
| `Gender Classification Model/` | Gender Prediction (Logistic Regression + Embeddings) | Flask API + Streamlit |
| `Hotel Recommender System/` | Hotel Recommendation (Collaborative Filtering / SVD) | Streamlit |
| `Airflow_Travel_System/` | Automated pipeline DAG | Apache Airflow |

---

## Prerequisites

- Python 3.10+ installed
- pip available
- Internet connection (for downloading sentence-transformers model ~90MB on first run)

---

## Quick Start (One Command)

```bash
# From project root:
python setup.py
```

This will:
1. Install all required packages
2. Train the Flight Price Prediction model (~3–5 min)
3. Train the Gender Classification model (~2–3 min + model download)
4. Train the Hotel Recommender model (~1 min)

---

## Manual Setup (Step by Step)

### 1. Install Dependencies

```bash
pip install numpy==1.26.4 pandas==2.2.0 scikit-learn==1.3.2 scipy==1.12.0 ^
    flask==3.0.2 "werkzeug>=3.0.0" joblib==1.3.2 xgboost mlflow>=2.10.0 ^
    streamlit>=1.30.0 sentence-transformers
```

### 2. Train Models

```bash
# Flight Price Prediction
cd Travel_ML_System
python train_models.py

# Gender Classification (downloads ~90MB model on first run)
cd "../Gender Classification Model"
python train_gender_model.py

# Hotel Recommender
cd "../Hotel Recommender System"
python train_hotel_model.py
```

## MLOps Components

### 📈 MLflow Experiment Tracking

```bash
# Start MLflow UI
mlflow ui --port 5000
# → Open http://localhost:5000

# Run flight price training with MLflow tracking
cd Travel_ML_System
python flight-price-pred-mlflow.py
```

### 🔄 Airflow DAG

The `Airflow_Travel_System/` folder contains an Airflow DAG for automated model retraining. Requires Apache Airflow installation:

```bash
pip install apache-airflow
export AIRFLOW_HOME=$(pwd)/Airflow_Travel_System/airflow
airflow db init
airflow webserver &
airflow scheduler &
# Copy the DAG
cp Airflow_Travel_System/flight_price_prediction_dag.py $AIRFLOW_HOME/dags/
```

### 🐳 Docker

```bash
# Flight Price API
cd Travel_ML_System
docker build -t flight-price-api .
docker run -p 8000:8000 flight-price-api

# Gender Classification
cd "Gender Classification Model"
docker build -t gender-classifier .
docker run -p 8000:8000 gender-classifier
```

## Troubleshooting

| Problem | Solution |
|---------|----------|
| `FileNotFoundError: flights.csv` | Run scripts from their own directory (e.g. `cd Travel_ML_System`) |
| `ValueError: X has n features but model expects m` | Delete old .pkl files and re-run `train_models.py` |
| `sentence_transformers not found` | `pip install sentence-transformers` |
| Model pkl files are tiny (< 1KB) | They're Git LFS pointers — run the training scripts to generate real models |
| MLflow connection error | Start `mlflow ui --port 5000` before running `flight-price-pred-mlflow.py` |
